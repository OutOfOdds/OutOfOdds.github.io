Moving Sessions

Dropping a File on iPad

On the iPad there's a quicker way to bring in a session than Import Session: drag the .pokersession file from Files, Mail or another app and drop it on the House Rules window. The same import sheet opens, and from there everything works as in Export and Import.

The example club

All the screenshots come from the Maple Street Game, Dave's home game on Maple Street.

  • The club: Dave hosts on Tuesdays for Marcus, Jenna, Tyler, Priya and Sam. They play No-Limit Hold'em at 4/8 blinds with a chip worth $0.25.
  • Marcus's iPad: Marcus keeps the Maple Street Game on his iPad, with Dave, Jenna and Tyler as members, next to his own club, the Office Game.
  • What happens: Dave sent Marcus the file for last Tuesday's game, played on November 17, and Marcus saved it to Files on his iPad. Sending and saving the file is in Export and Import. Now he brings it into House Rules.

Drop the file

House Rules takes a dropped file in its full iPad layout, with the sidebar on the left: the sections Tonight, Clubs and Library, and Settings at the bottom.

  1. Put Files and House Rules on the screen together: open Files, then House Rules, and arrange their windows side by side, or use Slide Over. Mail works the same way with a file in an email.
  2. Touch and hold the file until it lifts, then drag it onto the House Rules window and let go. Anywhere in the window works.
  3. The import sheet opens. Pick the club and the new members, then tap the check mark.

Nothing on the screen shows where to drop: the whole window takes the file.

The import sheet

The sheet is the same one Import Session opens, and it looks the same however you got to it; in the screenshot, Settings is behind it. Here it shows last Tuesday's game: November 17, 2026, 5 players. Marcus keeps Maple Street Game checked. Priya isn't a member of his copy of the club yet, so she's under New Members, checked, and she becomes a member with the import.

After the check mark, the session opens on the right, in place of the screen that was there, and a message says Session imported.

A file House Rules already has works the same way as on the iPhone: the same file again changes nothing, and a different version asks Replace or Skip. A game that was handed over to you opens with Handed over to you. You run this session from now on. See Export and Import.

Without dragging

When dragging is awkward, go to Settings in the sidebar, tap Import Session and pick the file. The file picker opens on the iPad's Files, here on Recents. On My iPad and iCloud Drive are under Locations.

Good to know

  • Drop several files at once, and only the first one is imported, with no message about the rest. Drop the others one at a time.
  • Dropping works in the full layout with the sidebar. When House Rules is in a narrow window, it shows the iPhone layout: use Import Session in Settings there.
  • Only .pokersession files are taken. The window doesn't take a photo or a PDF: nothing happens.
