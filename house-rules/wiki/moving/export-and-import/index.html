Moving Sessions

Export and Import

House Rules keeps your games on your phone. There's no account and no sync, so to move a session to another phone or iPad, you send it as a file. The file ends in .pokersession and carries the whole game: players, buy-ins and cash-outs, the cash box, expenses and the transfers of the settlement. A tournament travels the same way, with its entries, places and payouts.

This page shows how to send a session, how to bring it in on the other device, what happens when the same game arrives twice, and how to hand a running game to another host.

The example club

All the screenshots come from the Maple Street Game, Dave's home game on Maple Street.

  • The club: Dave hosts on Tuesdays for Marcus, Jenna, Tyler, Priya and Sam. They play No-Limit Hold'em at 4/8 blinds with a chip worth $0.25.
  • Marcus's phone: Marcus keeps the Maple Street Game on his own phone too, with Dave, Jenna and Tyler as members, and runs a second club of his own, the Office Game.
  • What happens: Dave sends Marcus last Tuesday's game, played on November 17 by five of them, without Sam. Tonight Dave has to leave early, so he hands the running game over to Marcus, who finishes it on his phone.

Send a session

Open the session and tap More, the button with three dots at the top right. Choose Share Session. For a tournament, the same item is called Share Tournament.

The share sheet opens with the file, here 11/17/2026, Maple Street Game. Send it with AirDrop, Messages or Mail, or tap Save to Files to keep it.

Dave keeps a copy: Save to Files, pick a folder, here On My iPhone, and tap Save. Then he sends the same file to Marcus by AirDrop, and Marcus saves it to Files on his phone. The share sheet shows the date the US way, 11/17/2026, but the file name always puts the day first and drops the spaces from the club's name: 17.11.2026-MapleStreetGame.pokersession.

You can share a session at any stage: while it's running, after it's closed and waiting for players to settle up, or when it's finished. Sharing never locks your copy, both phones keep working with it. In a club's list of sessions, touch and hold a session and choose Share to send it without opening it.

Import a file

On the other device, open the file and choose House Rules, for example by tapping it in Messages or Mail. Or go to Settings, the gear at the top of the Lobby, the screen House Rules opens on (on the iPad, Settings in the sidebar), and under Import and Export tap Import Session, then pick the file. Marcus picks 17.11.2026. The other file is tonight's game, which comes later on this page.

The Import Session sheet shows what's in the file and asks where it goes:

  • Session from File: the date, November 17, 2026, and 5 players.
  • Import to Club: your clubs. Marcus keeps Maple Street Game checked. Tap another club to pick it.
  • New Members: players in the file who aren't members of that club. Priya isn't in Marcus's copy of the club, so she's listed and checked.

A checked player becomes a member of the club. Uncheck a player who shouldn't be one: they stay in the session with their results, but the session won't count in the club's stats for them. Players who are already members are matched by name and aren't listed. See Clubs and Members.

Tap the check mark. The session opens on Marcus's phone with the same results and cash box, and a message says Session imported.

No club yet? The sheet offers a new club, Home Game, and all the players become its members. You can rename the club later.

The same game twice

House Rules recognizes a session it already has.

  • The same file again: nothing changes, and a message says Session already imported.
  • A different version: say Dave fixed a cash-out and sent the file again. House Rules asks Session Already Imported with Replace and Skip. Replace swaps your copy for the one in the file and erases your own edits to it, such as transfers you marked as done. Skip keeps your copy.

Your own session that went to another phone and came back unchanged is the same session too: it's recognized, not added twice.

Hand a running game over

Tonight Dave has to leave early, and Marcus will run the rest of the game. With two copies of a running game, both hosts could add rebuys and the totals would no longer match. Hand Over Session sends the game and locks Dave's copy, so there's only one host at a time.

Open the running session, tap More and choose Hand Over Session. For a tournament it's Hand Over Tournament. The item is only there while the game is running.

The share sheet opens with tonight's file, 11/24/2026, Maple Street Game. Send it to Marcus the way you'd send any file.

Once the file has gone, Dave's copy is read-only: the screen says This session was handed over to another host. To make changes here, take it back. Dave can still look at everything, including the cash box. If you close the share sheet without sending, nothing is locked.

Take Back unlocks Dave's copy. It asks first, because changes made on the other phone won't come with it: Take Back Session? To keep Marcus's changes, ask him to hand the game back instead. Take Back doesn't reach Marcus's phone: his copy stays open there, so agree who runs the game from now on.

On Marcus's phone, the import sheet says Handed over to you. You run this session from now on. Priya became a member with the last import, so there are no new members this time.

After the check mark, tonight's game opens on Marcus's phone as a Live Session he can change: the same five players, 2,400 chips on the table and $600 in the cash box.

To give the game back, Marcus opens it, taps More, Hand Over Session and sends the file to Dave, who opens it in House Rules. Then:

  • Unchanged: Dave's copy unlocks and a message says Session is back.
  • With Marcus's changes: the import sheet says Back from the other host with their changes. You run this session here again. The check mark replaces Dave's copy with Marcus's, without asking about Replace, and unlocks it.

The blind timer doesn't travel with the game. Start it again on the new host's device, see Running the Timer.

When a file won't import

The message Couldn't Import Session says what's wrong and what to do:

  • The file is damaged or isn't a House Rules session. Ask the sender to send it again.
  • The file is from a different version of House Rules. Update the app on both devices, then open the file again.
  • Two players in the file match one member of the club, for example two players called Sam in the file and one Sam in the club. Choose another club, or ask the sender to rename one of them.
  • The app can't access the file. Save it to Files and choose it from there.

Good to know

  • Both devices need the same version of House Rules.
  • The club's color, house rules and seasons stay on each device: the file carries the session, not the club.
  • A file larger than 5 MB isn't a House Rules session and isn't imported.
  • On the iPad you can also drop a file on the window, see Dropping a File on iPad.
