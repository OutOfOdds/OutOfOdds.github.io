Moving Sessions

Handing a Session Over

When you can't stay until the end of the game, another host can run the rest of it on their phone. Hand Over Session sends the running game as a file and locks your copy, so only one phone runs the game at a time. This page shows how to hand a game over, how the new host takes it, and how the game comes back.

The example club

All the screenshots come from the Maple Street Game, Dave's home game on Maple Street.

  • The club: Dave hosts on Tuesdays for Marcus, Jenna, Tyler, Priya and Sam. They play No-Limit Hold'em at 4/8 blinds with a chip worth $0.25.
  • Marcus's phone: Marcus keeps the Maple Street Game on his own phone too, and runs a second club of his own, the Office Game. Last week Dave sent him the November 17 game, see Export and Import, so Priya is already a member there.
  • What happens: tonight, November 24, Dave has to leave early, so he hands the running game over to Marcus, who finishes it on his phone.

Why not just share it

With two copies of a running game, both hosts could add rebuys and the totals would no longer match. Hand Over Session sends the game and locks Dave's copy, so there's only one host at a time.

Share Session, the item next to it, never locks anything: both phones keep a copy you can change, and changes from two phones never merge. Use it to send a copy for the record, see Export and Import.

Hand it over

Open the running session, tap More and choose Hand Over Session. For a tournament it's Hand Over Tournament. The item is only there while the game is running.

The share sheet opens with tonight's file, 11/24/2026, Maple Street Game. Send it to Marcus the way you'd send any file.

Once the file has gone, Dave's copy is read-only: the screen says This session was handed over to another host. To make changes here, take it back. Dave can still look at everything, including the cash box. If you close the share sheet without sending, nothing is locked.

The new host takes over

On Marcus's phone, the import sheet says Handed over to you. You run this session from now on. Priya became a member when Marcus imported last Tuesday's game, so there are no new members this time.

After the check mark, tonight's game opens on Marcus's phone as a Live Session he can change: the same five players, 2,400 chips on the table and $600 in the cash box.

The new host doesn't need your club. They pick one of their own clubs in the import sheet, or the session goes to a new club if they have none. Players who aren't members there are listed under New Members.

Hand it back

To give the game back, Marcus opens it, taps More, Hand Over Session and sends the file to Dave, who opens it in House Rules. Then:

  • Unchanged: Dave's copy unlocks and a message says Session is back.
  • With Marcus's changes: the import sheet says Back from the other host with their changes. You run this session here again. The check mark replaces Dave's copy with Marcus's, without asking about Replace, and unlocks it.

Take it back without the file

Can't wait for the file? Take Back unlocks Dave's copy. It asks first, because changes made on the other phone won't come with it: Take Back Session? To keep Marcus's changes, ask him to hand the game back instead. Take Back doesn't reach Marcus's phone: his copy stays open there, so agree who runs the game from now on.

Good to know

  • Hand Over Session is in the More menu until the session is finished. For a tournament it's Hand Over Tournament.
  • Close the share sheet without sending, and nothing is locked.
  • A locked copy is read-only: you can still look at everything, including the cash box.
  • Take Back doesn't reach the other phone. Their copy stays open, so agree who runs the game from now on.
  • Changes from two phones never merge. When a different version comes back, you keep one copy or the other, so let only one host make changes at a time.
  • The blind timer doesn't travel with the game. Start it again on the new host's device, see Running the Timer.
  • iCloud sync is for your own iPhone and iPad, not for another host's phone. Between your own devices, the game is already the same everywhere, see Sync with iCloud.
